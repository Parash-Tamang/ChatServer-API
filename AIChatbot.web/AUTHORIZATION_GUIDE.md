## Token Details

### Access Token
- **What**: JWT signed with HS256 algorithm
- **Contains**: 
  - `sub` - User ID
  - `email` - User email
  - `roles` - User roles
  - `exp` - Expiration time
- **Expiration**: 60 minutes (configurable in API appsettings.json)
- **Storage**: HTTP-only cookie (cannot be accessed by JavaScript)
- **Used For**: API requests (Chat operations, etc.)

### Refresh Token
- **What**: Secure random 64-byte token (Base64 encoded)
- **Expiration**: 7 days
- **Storage**: HTTP-only cookie + hashed in database
- **Used For**: Obtaining new access token when current one expires

## Security Features

? **HTTP-Only Cookies** - Prevents JavaScript access (XSS protection)  
? **Secure Flag** - Tokens only sent over HTTPS  
? **SameSite=Strict** - Prevents CSRF attacks  
? **JWT Validation** - Token signature verified on backend  
? **Token Expiration** - Automatic expiration after configured time  
? **Refresh Token Rotation** - Old refresh token revoked when new one issued  
? **Server-side Validation** - Cannot bypass with JavaScript manipulation

## Configuration

Update `appsettings.json` to match your API:

```json
{
  "ApiSettings": {
    "BaseUrl": "https://localhost:7048"  // Your API URL
  }
}
```

The API's JWT configuration is in `AIChatbot.Api/appsettings.json`:
- `Jwt:Key` - Secret key for signing tokens
- `Jwt:Issuer` - Who issued the token
- `Jwt:Audience` - Who can use the token
- `Jwt:AccessTokenExpirationMinutes` - 60 minutes
- `Jwt:RefreshTokenExpirationDays` - 7 days
